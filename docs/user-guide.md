# 用户指南

## 1. 创建项目并导入

在“项目”页新建项目，上传目录或 ZIP。首次体验可用 `token-traffic-demo.zip`。导入完成后先查看诊断：绿色表示完整解析，黄色表示降级或低置信度，红色表示无法解析。

## 2. 查看资产

“数据资产”按 RDS、ODS、DWD、DWS、ADS 分层列出表。点击表可查看字段角色、数据粒度、时间字段、加工脚本、上下游及数据剖析。自动分类是建议；业务确认后可标记为“人工确认”。

## 3. 追踪血缘

在“血缘分析”搜索表或字段，选择上游、下游或双向及展开层数。点击连线可查看原始 SQL、文件和语句位置。字段级关系缺少 DDL 或遇到动态 SQL 时会显示覆盖率，而不是假设完整。

## 4. 检查作业顺序

“作业流”将 SQL 读写关系生成 DAG，并叠加 `jobs.csv`。实线为确认关系，虚线为推断关系。可人工确认、禁用或补充边；人工覆盖不会被重新解析覆盖。

## 5. 查看指标与时间口径

“指标口径”展示公式、分组维度、过滤条件、去重键、时间字段和时区。重点检查同名指标的过滤差异，以及分钟、小时、日报是否使用同一业务时间。

演示包预置三个发现：

1. 分钟表使用 `event_time`，小时表使用 `ingestion_time`。
2. 实时报表使用 `SELECT *`。
3. 日报排除 `TEST`，DWS 小时指标不排除。

## 6. 执行变更影响分析

选择表、字段或 SQL 逻辑并描述拟变更，系统输出直接影响、传递影响、指标语义影响和潜在回刷范围。报告只提供决策证据，不修改生产 SQL。

典型验证：

- 将 `dwd_token_request.region_code` 从 `VARCHAR(16)` 改为 `VARCHAR(32)`，应追踪到 DWS、ADS 及固定长度 CAST。
- 删除字段时，应识别显式引用和 `SELECT *` 风险。
- 修改成功率过滤条件时，应提示同名指标口径变化。

## 7. 比较版本

分别导入当前版和候选版，在“版本比较”选择两批数据。系统忽略注释和格式差异，报告 DDL、SQL 语义、血缘、粒度和指标变化，并可跳转影响分析。

## 8. 使用数据助手

助手只根据已解析元数据、相关 SQL 片段和人工确认术语回答。每个结论应带表、字段、脚本证据；没有证据时显示“不确定”。未配置模型不影响解析、血缘和影响分析。

## 安全建议

- 默认离线导入，不连接生产 DWS。
- 样例必须脱敏。
- 外部模型默认不接收原始样例值。
- 影响报告不能替代发布评审和回刷容量评估。
