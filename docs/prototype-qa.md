# DataFlow Inspector 可点击原型验收清单

## 1. 验收目标与范围

本清单用于验收无真实后端依赖的 DataFlow Inspector 前端原型。验收范围包括：

- 9 个业务页面及页面间导航；
- Token 请求流量演示数据的一致性；
- 搜索、筛选、抽屉、标签页和反馈状态；
- 表级/字段级血缘交互；
- 作业流、指标口径、变更影响、版本比较和 AI 助手；
- 响应式、键盘可访问性和减少动态效果；
- 独立 HTML 离线运行及交付截图质量。

不在本轮验收范围内：真实 SQL 解析、生产数据库连接、真实模型调用、用户权限和生产性能。

## 2. 测试环境与前置条件

### 2.1 建议环境

- Chromium 系浏览器最新版；
- Firefox 最新版（兼容性抽查）；
- 桌面视口：`1440 × 900`；
- 窄屏视口：`768 × 1024`；
- 移动视口抽查：`390 × 844`；
- 浏览器缩放：100%，另以 200% 抽查文本可读性；
- 浏览器控制台全程保持打开。

### 2.2 前置条件

- 原型已生成生产构建；
- 演示数据包含 RDS/CDM、ODS、DWD、DWS、ADS 五个层级；
- 页面内至少存在 3 个预置变更案例；
- 所有模拟接口均可在无网络条件下返回结果；
- 待验收的独立 HTML 和截图均位于 `outputs/`。

### 2.3 缺陷等级

| 等级 | 定义 |
|---|---|
| P0 | 页面无法打开、独立 HTML 无法运行、核心数据不可见或持续崩溃 |
| P1 | 关键路径不可完成，如导航、血缘查看、影响分析或版本比较失效 |
| P2 | 局部交互、响应式、无障碍或数据一致性明显异常，但存在绕行方式 |
| P3 | 轻微视觉、文案、对齐或非关键体验问题 |

## 3. 通用验收

- [ ] 首次打开无白屏，主布局、侧边栏、顶栏和内容区完整显示。
- [ ] 浏览器控制台无未捕获异常、资源 404、无限请求或重复 key 警告。
- [ ] 9 个页面均可通过侧边栏到达，当前菜单状态清晰。
- [ ] 浏览器前进、后退可恢复正确页面。
- [ ] 刷新任一子页面不会进入空白页或错误页。
- [ ] 顶部项目名、当前版本和全局操作在各页面保持一致。
- [ ] RDS/CDM、ODS、DWD、DWS、ADS 的名称和颜色在所有页面一致。
- [ ] 表名、字段名、指标名、脚本名和行号在跨页面跳转后保持一致。
- [ ] 所有按钮有可辨识的默认、悬停、按下、焦点和禁用状态。
- [ ] 弹窗、抽屉、下拉框可通过关闭按钮、取消按钮和 `Esc` 关闭。
- [ ] 模拟异步操作展示加载状态，加载期间不会重复提交。
- [ ] 操作成功有明确反馈；失败状态包含原因和可执行的恢复入口。
- [ ] 空结果不会只显示空白区域，应展示说明及清除筛选入口。
- [ ] 长表名、字段名、SQL 和中文说明不会破坏布局，并可查看完整内容。

## 4. 九个页面功能验收

### 4.1 项目总览

- [ ] 资产、字段、指标和风险摘要均有数值与标签。
- [ ] 点击层级或资产摘要可进入数据资产页，并带入相应筛选。
- [ ] 点击风险摘要可定位到质量问题或相关详情。
- [ ] 四五条作业流均可见，点击后进入对应作业流视图。
- [ ] “导入新版本”能打开模拟上传界面，并可取消。
- [ ] 最近发现中的时间口径、`SELECT *` 等风险可点击查看证据。
- [ ] 作业流脉冲带点击层级后有明确选中状态和对应结果变化。

### 4.2 数据资产

- [ ] 可按表名、字段名和中文描述进行不区分大小写搜索。
- [ ] 搜索前后空格不会影响结果；清空搜索恢复完整列表。
- [ ] 层级、作业流、风险筛选可单独使用，也可组合使用。
- [ ] 当前筛选条件可见，并可一键清除。
- [ ] 表格/卡片视图切换后数据集合和选中条件保持一致。
- [ ] 无匹配结果时显示空状态和“清除筛选”操作。
- [ ] 点击表进入正确表详情。
- [ ] 点击上下游数量进入血缘页，并聚焦对应表。
- [ ] 表层级、粒度、时间字段、上下游数量与表详情一致。

### 4.3 表详情

- [ ] 基础信息、字段、加工逻辑、上下游、指标、数据样例标签页均可切换。
- [ ] 页面展示正确层级、粒度、加工脚本、直接上下游。
- [ ] 字段列表展示字段角色、来源、加工方式和置信度/证据。
- [ ] 点击时间、维度或指标字段可进入正确字段级血缘。
- [ ] 点击 SQL 证据打开代码侧栏，并定位到正确脚本和行号。
- [ ] 点击“查看血缘”后以当前表为中心打开血缘页。
- [ ] 点击“分析变更”后进入变更页，并预填当前表或字段。
- [ ] 数据样例明确标识为演示/脱敏数据。

### 4.4 血缘分析

- [ ] 默认血缘图完整显示，节点不会全部重叠或超出画布。
- [ ] 表级/字段级切换后节点和连线语义正确。
- [ ] 上游、下游、双向切换能正确改变展示范围。
- [ ] 1～5 层范围切换生效，层数减少时非范围节点被移除或折叠。
- [ ] 搜索表或字段后目标节点被聚焦并高亮。
- [ ] 点击节点显示对象详情、层级、字段/指标和上下游摘要。
- [ ] 点击边显示来源、目标、转换表达式、脚本名和行号。
- [ ] 高亮传播路径时，非路径节点弱化但仍可辨识。
- [ ] 展开/折叠维度表不会丢失当前选中对象。
- [ ] 缩放、平移、适应画布和重置视图均有效。
- [ ] 触控板/鼠标滚轮不会导致页面与画布发生不可控滚动冲突。
- [ ] 字段级时间链路可展示 `event_time → stat_minute → stat_hour → stat_date`。
- [ ] 指标血缘能区分直接映射、聚合、条件计算和派生公式。
- [ ] 无证据或低置信度血缘有明确视觉标识，不与已确认关系混淆。

### 4.5 作业流

- [ ] 可切换不同业务流，节点和依赖关系随之更新。
- [ ] 已确认、SQL 推断、未知依赖有不同图例和视觉表达。
- [ ] 点击作业节点可查看脚本、输入表、输出表和调度信息。
- [ ] 可并行分支、串行依赖和汇聚节点表达正确。
- [ ] 循环依赖、断点和缺失调度信息有明确提示。
- [ ] 模拟确认推断依赖后，状态立即变化并有成功反馈。
- [ ] 撤销人工确认后恢复推断状态，不删除原有演示数据。

### 4.6 指标口径

- [ ] 可按指标名、字段名或中文含义搜索。
- [ ] 粒度、作业流和状态筛选可组合使用。
- [ ] 指标详情展示公式、来源、粒度、维度、时间口径、过滤和去重键。
- [ ] 同名不同口径可并排比较，差异字段被突出。
- [ ] `request_cnt`、`success_cnt`、`success_rate` 等预置指标定义自洽。
- [ ] 点击来源字段进入字段血缘；点击使用位置进入相应表或路径。
- [ ] 点击“分析变更”后正确预填指标对象。
- [ ] “自动推断”与“人工确认”状态有明确区分。

### 4.7 变更影响分析

- [ ] 3 个预置案例均可一键载入，输入内容与案例说明一致。
- [ ] 可手工选择变更对象、变更类型，并填写修改前后内容。
- [ ] 必填项缺失时阻止提交，并在对应字段附近显示错误。
- [ ] 点击“开始分析”后有加载状态，且不会重复创建结果。
- [ ] 结果展示风险等级、直接影响、传递影响、指标数和 ADS 数。
- [ ] 影响路径可展开，并能从 DWD 追踪到最终 ADS。
- [ ] 推荐修改顺序与依赖方向一致，上游修改不会排在下游之后。
- [ ] 报告展示结构影响、语义影响和运行/回刷风险。
- [ ] `VARCHAR(16)` 固定转换与 `SELECT *` 风险能在对应案例中出现。
- [ ] 点击受影响对象可跳转详情，返回后分析结果仍保留。
- [ ] 切换案例或重置时旧结果被明确清除，不与新输入混淆。

### 4.8 版本比较

- [ ] 可选择两个不同版本；选择相同版本时阻止比较并提示原因。
- [ ] 比较结果包含新增、修改、删除分类及摘要计数。
- [ ] 按变化类型筛选后列表和计数保持一致。
- [ ] 文本差异/语义差异切换有效，格式变化不会被误标为语义变化。
- [ ] 字段类型、过滤条件、指标口径和血缘变化均有演示样例。
- [ ] 点击差异项可查看修改前后详情及影响摘要。
- [ ] 点击“分析影响”后将对应变更带入变更分析页。
- [ ] 交换左右版本后新增/删除方向正确反转。

### 4.9 数据助手

- [ ] 预置问题可点击发送，用户问题与模拟回答正确配对。
- [ ] 自定义问题可提交；空白问题不能发送。
- [ ] 模拟逐字输出期间有停止/等待状态，且界面不会跳动失焦。
- [ ] 回答引用表、字段、指标、脚本和行号等证据。
- [ ] 点击证据可跳转到正确详情、指标或血缘位置。
- [ ] “查看指标”“打开血缘”“分析变更影响”快捷操作可用。
- [ ] 缺乏证据的问题明确回答“不确定”，不伪造来源。
- [ ] AI 未配置/模拟失败状态不影响其他页面，并提供重试或返回入口。

## 5. 搜索与筛选专项

- [ ] 中文、英文、下划线表名均可搜索。
- [ ] 搜索词高亮不会改变原始文本内容。
- [ ] 连续快速输入不会导致旧结果覆盖新结果。
- [ ] 多筛选组合后的结果满足所有已选条件。
- [ ] 清除单个筛选只移除该条件；“全部清除”恢复默认状态。
- [ ] 跨页面跳转携带的筛选在 URL 或页面状态中可解释、可恢复。
- [ ] 返回上一页后搜索词、筛选和滚动位置尽可能保留。

## 6. 响应式与缩放

- [ ] `1440 × 900` 下主要内容无需页面级横向滚动。
- [ ] `768 × 1024` 下侧边栏可折叠，核心操作仍可到达。
- [ ] `390 × 844` 下不要求完整图谱同屏，但必须可平移/缩放且控制栏可用。
- [ ] 数据表在窄屏采用横向容器、字段裁剪或卡片布局，不挤压到不可读。
- [ ] 抽屉和弹窗不会超出视口，内部内容可滚动。
- [ ] 浏览器 200% 缩放时，无重要文字或操作被永久遮挡。
- [ ] 横竖屏切换后页面不会白屏或丢失当前选择。

## 7. 键盘与基础可访问性

- [ ] 从地址栏开始仅使用键盘可到达所有主要导航和操作。
- [ ] `Tab` 顺序与视觉阅读顺序一致，不进入隐藏元素。
- [ ] 所有可交互元素均有清晰可见的焦点样式。
- [ ] 原生按钮或等价语义元素可用 `Enter`/`Space` 激活。
- [ ] 弹窗打开后焦点进入弹窗并受约束，关闭后返回触发元素。
- [ ] `Esc` 可关闭最上层弹窗、抽屉或菜单。
- [ ] 图标按钮有可读的 `aria-label` 或可见文本。
- [ ] 表单控件具有明确标签，错误信息可被辅助技术关联。
- [ ] 颜色不是区分层级、风险和状态的唯一手段，同时提供文字、图标或线型。
- [ ] 主体文字和关键操作具备足够对比度。
- [ ] 血缘图至少提供可聚焦节点和文本化关系详情，不只依赖画布视觉。

## 8. 减少动态效果

在操作系统或开发者工具中启用 `prefers-reduced-motion: reduce` 后执行：

- [ ] 作业流脉冲、路径传播和数字动效被关闭或显著缩短。
- [ ] 页面切换、抽屉和弹窗不使用大幅移动或持续动画。
- [ ] AI 模拟输出可直接显示或以低动态方式更新。
- [ ] 关闭动画后，状态变化仍能通过颜色、文字或图标被理解。
- [ ] 不存在闪烁、快速循环或无法暂停的动画。

## 9. 独立 HTML 离线验收

### 9.1 操作步骤

1. 断开网络，或在开发者工具中启用 Offline。
2. 关闭已打开的原型标签页，清理对开发服务器的依赖。
3. 直接打开 `outputs/dataflow-inspector-prototype.html`。
4. 逐页执行关键路径：总览 → 资产 → 表详情 → 血缘 → 变更分析 → 版本比较 → 助手。

### 9.2 验收项

- [ ] 文件存在且非空。
- [ ] 直接打开后无白屏，无需启动本地服务。
- [ ] CSS、图标、字体、脚本和演示数据均内嵌或使用可离线资源。
- [ ] 控制台无 `file://` 跨域错误和资源加载失败。
- [ ] 9 个页面均可导航；若使用 hash 路由，刷新/返回行为正常。
- [ ] 血缘图、变更分析和版本比较在离线状态完整可用。
- [ ] 原型不向 `127.0.0.1:8080` 或任何外部地址发起请求。
- [ ] 文件名稳定，重新交付不会引用带随机哈希的外部资源。

## 11. 关键业务一致性抽查

- [ ] `dwd_token_request` 的 `event_time` 可追踪到 `dws_token_minute.stat_minute`。
- [ ] `stat_minute` 可继续传播到 `dws_token_hour.stat_hour` 和 ADS 日期字段。
- [ ] `request_cnt` 来源和 `COUNT(*)` 口径在表详情、指标页、血缘页一致。
- [ ] `success_rate` 的分子、分母和过滤条件在指标页与助手回答一致。
- [ ] 分钟表使用 `event_time`、小时表误用 `ingestion_time` 的风险在相关页面一致出现。
- [ ] `region_code VARCHAR(16) → VARCHAR(32)` 案例能传播到相应 DWS 和 ADS。
- [ ] 版本比较中的变化可无损带入变更分析。

## 14. 最关键的五项风险

1. **独立 HTML 实际依赖开发服务器或 CDN**：在线开发时正常，离线交付后可能白屏、图标缺失或路由失效。
2. **血缘图信息密度过高**：节点重叠、连线交叉和滚轮冲突会让最核心页面不可用，必须重点复核聚焦、折叠和适应画布。
3. **跨页面 Mock 数据口径不一致**：同一字段、指标或风险若在资产、血缘、影响分析和助手中说法不同，会直接损害产品可信度。
4. **变更影响结果只有数字没有证据链**：若无法定位到表、字段、脚本和行号，原型无法验证产品最重要的决策价值。
5. **画布控件和自建组件键盘不可达**：鼠标演示可用但键盘、窄屏或减少动态效果下失效，会造成关键交互路径缺失。
