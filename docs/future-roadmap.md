# 未来演进清单

## 当前决策

DataFlow Inspector 当前停在 P2 可用版本，面向约 5 人的可信内部小组。P3 不作为当前验收、试用或日常使用的阻断项。

以下条目仅进入未来清单，不在没有明确触发条件时提前建设。

## P3：生产治理与规模化

### 身份与权限

- 用户登录、会话管理和退出。
- 项目级角色与读写权限。
- 敏感导入、导出和元数据修改权限。

启动条件：系统暴露到非可信网络、使用者不再全部可信，或不同项目需要数据隔离。

### 审计与协作

- 操作审计日志和审计检索。
- 元数据编辑乐观锁与冲突处理。
- 关键变更审批或复核。

启动条件：多人频繁同时编辑、需要追责，或出现覆盖他人修改的实际问题。

### 性能与容量

- 资产、导入历史和修订记录服务端分页。
- 大型血缘图按深度、方向和节点范围查询。
- 查询缓存、索引优化和后台任务容量控制。
- 单表导入异步化。

启动条件：单项目资产或版本量明显增长、页面出现可测量延迟，或同步单表导入影响交互。

### 运维与合规

- 结构化监控、告警和容量指标。
- 正式备份恢复策略与恢复演练。
- 自动化部署、版本回滚和数据库迁移发布流程。
- 数据保留、脱敏和合规策略。

启动条件：形成稳定生产服务、需要服务等级承诺，或接入受监管数据。

## P2 后的工作方式

当前不再安排新的架构阶段。后续工作以真实试用反馈为输入：

1. 使用 `make check` 和 `make p2-check` 保持当前基线。
2. 只修复真实用户遇到的功能缺陷和高频体验问题。
3. 新需求优先验证是否属于 5 人内部使用的必要能力。
4. 满足上述触发条件后，再拆分相应 P3 子项，不默认一次性实施完整 P3。
