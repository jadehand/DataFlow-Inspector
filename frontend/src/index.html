✦
request_success_rate 来自分钟聚合表中的两个指标：
success_cnt / nullif(request_cnt, 0)
success_cnt 统计 status = 'SUCCESS' 的请求；数据粒度为“局点 + 租户 + 模型 + 分钟”，使用 event_time 截断到分钟。
